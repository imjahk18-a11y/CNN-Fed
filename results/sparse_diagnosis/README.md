# Sparse 3D CNN 성능 진단

[동일 학습량의 7점·27점 비교 보고서](run01/report.md)에서 Synthetic 검증과 WMSC 외부 평가, 실제 입력·수용영역, Ground 오분류 분석을 확인할 수 있다. 확정된 실험의 설정과 체크포인트는 [run01](run01)에 있다.

이 디렉터리 루트의 protocol.json은 최초 입력 검사 기록이다. CPU와 GPU 간 RGB/255를 비트 단위로 비교했을 때 float32 반올림 차이가 발생해 모델 학습 전에 종료했다. run01에서는 각 값의 차이가 1 ULP 이내인지 확인하고 좌표·레이블·체크포인트 복원은 정확히 대조했다.
