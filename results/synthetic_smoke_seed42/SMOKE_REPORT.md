# 합성 분할 데이터의 CPU 실행 기록

2026년 11월 18일, 입력 변형 A(occupancy, 패치 내 상대 높이), 패치 32³, seed 42로 실행했다. train 25개를 중앙 학습 13개와 로컬 풀 12개로 나누고, validation 5개와 test 7개를 따로 생성했다. 두 클라이언트는 각각 6개 패치를 사용했다. 테스트 자료의 두 클래스는 생성기의 표면과 입체 물체이다.

```bash
python3 -m experiments.run_experiments smoke --out results/synthetic_smoke_seed42
```

PyTorch 2.0.1 CPU, AMD EPYC 7352, CPU 스레드 2개에서 실행했다. 사전학습 손실은 4 epochs 동안 0.29067 → 0.13658 → 0.11618 → 0.10666이었다. 가장 높은 validation mIoU는 첫 epoch의 0.96765였으며 그 체크포인트가 모든 비교의 원본이다.

|---|---|---:|---:|---:|---:|---:|---:|
|0%|8/16/8|9,154|198,705,152|—|0.98098|13.49|0.295168|
|20%|6/13/6|5,572|120,496,128|0.56901|0.89159|58.11|0.180096|
|40%|5/10/5|3,697|81,059,840|0.14913|0.14913|47.49|0.119776|

프루닝 모델의 중앙 미세조정은 1 epoch이다. 20% 모델의 mIoU는 일부 회복되었고 40% 모델은 같은 값에 머물렀다. 단일 패치 CPU 추론은 3회 예열 후 8회 측정했다. 이 환경에서는 두 프루닝 모델의 p50이 원본보다 길었다. GPU 자원과 엣지 보드 지연시간은 측정 전이다.

3개 모델 × 2개 분포 × 2 rounds가 완료되었다. 통신량은 시뮬레이션에서 배포 및 회수한 모델 텐서 크기로 계산했다. 각 round의 validation 지표와 로컬 훈련 시간, 실제 test의 클래스별 IoU와 CPU 지연은 CSV에서 확인할 수 있다. [라운드 기록](results/federated_round_metrics.csv) · [모델별 측정](results/experiment_results.csv) · [프루닝 전후](results/pruning_comparison.csv)

이 실행은 학습·복원·양쪽 클라이언트 집계와 산출물 생성을 검증한다. 실제 STPLS3D에서의 정확도와 현장 탑재 성능은 미측정이다.
