# 독립 사전학습과 장면 변경에 따른 2-client FedAvg 재현성

## 결과 요약

독립 사전학습 모델의 30라운드 최종 평가에서 INT8 − FP32 차이는 reference 분할 2.90 ± 1.56%p (3/3 양수) · rotated 분할 -3.55 ± 0.40%p (0/3 양수)였다. 아래의 ‘최종 평가’는 조기 중단에 쓰지 않은 별도 패치(audit)에서의 측정이다. ±는 각 분할 안의 서로 다른 초기화 3개의 표본 표준편차다.

FP32 업데이트 크기 조절의 최종 평가 이득은 독립 시작점 6개 중 3개에서 양수였다. INT8 온라인 조기 중단은 30R 대비 0.5%p 이내 유지 기준을 6/6회 충족했고, 0R 대비로는 6/6회 충족했다. 기준은 실행 전에 고정했다. 작은 표본에서 동등성을 통계적으로 검정한 결과는 아니다.

## 기존 결과 재현과 새 실험 구성

기존 Phase 3의 시드 42 체크포인트와 클라이언트·검증 패치를 불러온 검산에서 FP32, INT8, FP32_MATCH 세 조건 모두 0~30R mIoU와 30R 모든 가중치가 기존 기록과 정확히 일치했다. 과거 세 시드 평균 35.33%, 36.74%, 36.48% 및 INT8 조기 중단 37.53%는 한 사전학습 모델에서 파생된 수치다. 검산 실행은 독립 표본 수에서 제외했다.

## BN 처리 방식별 결과

- **aggregate**는 BN affine·running moments를 공유하고 배치 카운터는 기존 FedAvg 규칙인 최댓값으로 집계했다.
- **frozen**은 로컬 forward에서도 시작 모델의 running moments를 사용하고 고정했다. affine에는 gradient를 적용했다.
- **private**는 BN affine·moments·counter를 클라이언트에 유지하고 나머지만 교환했다. 공통 입력에 대한 두 personalized 모델의 혼동행렬을 합산해 mIoU를 구했다. 실제로는 두 개인화 모델의 성능을 나타내며 한 서버 모델의 예측과 다르다.

## 조기 중단의 일반화

Phase 3와 같은 온라인 규칙(min_delta=0, patience=3)을 고정했다. 전체 궤적에서 현재까지의 점수만 순차로 읽고 중단 시점까지 최고였던 모델을 복원했다. 30R까지 관측한 사후 최고 라운드는 따로 기록했다. 모든 방법의 선택 라운드와 체크포인트 해시를 고정한 뒤 최종 평가용 패치에서 처음으로 모델 점수를 계산했다. 그 전에는 패치 중복과 클래스 분포만 점검했다. 아래 세션 비용은 실측한 중단 prefix에 같은 길이의 종료 프레임을 더한 값이며, 실제 각 실행은 비교를 위해 30라운드까지 수행했다.

유지는 중단 모델의 최종 평가 mIoU가 비교 시점보다 0.5%p를 초과해 낮아지지 않은 경우로 정의했다. 시작점과 30R에 대해 별도 판정했으며, 10R 고정 종료 성능과 네 BN 정책의 결과도 저장했다. 같은 검증 장면의 공간적으로 분리된 패치이므로 새로운 비행 지역에서의 독립 시험과는 평가 범위가 다르다. [시드별 중단·통신량·유지 판정](early_stopping_generalization.csv)

**실제 서버에서 필요한 자료.** aggregate·frozen·recalibrated의 온라인 중단에는 서버가 보유한 대표 입력과 정답이 필요하다. private는 양쪽 클라이언트에도 같은 읽기 전용 검증 세트를 배포해 각각 지표를 계산했다. 이 연구 서버에서는 가능했지만 실기체 서버에 이런 레이블이 제공된다는 증거는 없다. 별도 보정용 영역의 입력도 설치 전에 확보해야 한다. 레이블 없는 서버는 이 mIoU 중단 규칙을 직접 실행할 수 없으며, 사전에 합의한 고정 라운드의 측정값은 그 경우의 대조 기준이다.

## 해석 범위와 재현

보정 영역의 구성은 reference Ground 66.56% · Fence 0복셀, rotated Ground 63.65% · Fence 0복셀이었다. 재보정 결과는 이 96패치의 입력 분포에 조건부이며 다른 보정 영역을 뽑았을 때의 변동성은 측정하지 않았다.

reference에서 동일한 INT8 학습 파라미터에 보정용 영역의 BN 통계를 적용했을 때 최종 평가 변화는 -2.85 ± 0.49%p였다. 같은 분할에서 기본 INT8의 조기 중단은 평균 0.220 MB를 사용했고 30R 대비 최종 평가 차이는 0.57 ± 0.48%p였다.

rotated에서 동일한 INT8 학습 파라미터에 보정용 영역의 BN 통계를 적용했을 때 최종 평가 변화는 -4.76 ± 2.11%p였다. 같은 분할에서 기본 INT8의 조기 중단은 평균 0.527 MB를 사용했고 30R 대비 최종 평가 차이는 0.55 ± 0.93%p였다.

기존 연구는 장면 12 전체를 평가한 이력이 있다. reference 최종 평가 패치는 이번 독립 모델의 학습과 라운드 선택에서 분리했지만 연구 전체에서 처음 공개되는 자료는 아니다. rotated의 장면 3 역시 과거 모델의 클라이언트 학습 장면이었다. 새 분할의 모델은 이 과거 가중치를 불러오지 않았다.

기본 mIoU는 정답·예측 모두에 없는 클래스를 평균에서 제외한다. reference의 최종 평가 패치에는 Fence 정답이 0개여서 분할 간 절대 점수를 직접 비교하기 어렵다. 양쪽 모두 정답이 존재하는 동일 다섯 클래스(Ground~Light pole)로 30R mIoU를 다시 집계한 INT8 − FP32 차이는 reference 2.90 ± 1.56%p, rotated -4.26 ± 0.48%p였다. 이 민감도 분석은 중단 결정에 사용하지 않았다. [클래스 지원 수와 민감도](class_support_sensitivity.csv)
