# STPLS3D Synthetic-to-Real 분할 실험

기준 모델의 합성 검증 mIoU는 0.3253, WMSC 외부 mIoU는 0.1778였다. 20% 모델은 같은 LR·epoch로 더 학습한 원본과 WMSC에서 +0.02%p 차이를 보였다. FL 후 여섯 조건의 WMSC 변화 범위는 시작점 대비 -4.58~-0.82%p였다.

공식 Synthetic_v3의 독립 장면 네 곳에서만 사전학습·미세조정·연합학습·모델 선택을 수행했다. WMSC는 모든 체크포인트를 확정한 뒤 동일한 외부 평가에 사용했다.

## 데이터와 검증

공유 ZIP에서 가장 작은 GTv3 네 장면 1.425 GB만 선택적으로 받았다. v1·v2·v3 배포 목록을 비교했고, 한 버전 안에서 스키마를 고정했다. 다운로드 전 부분 표본의 ID, 전체 다운로드 후 원시 ID 빈도·CRC32·SHA-256을 각각 기록했다. [아카이브·헤더 기록](acquisition.json) · [공식 데이터 정의](https://github.com/meidachen/STPLS3D#2-dataset)

|용도|합성 장면|사용 패치|
|---|---|---:|
|val|12_points_GTv3|384|
|central|13_points_GTv3|512|
|drone_A|3_points_GTv3|250|
|drone_B|4_points_GTv3|251|

0.3 m, 32³, occupancy·패치 바닥 기준 정규화 높이·RGB의 5채널이다. 중앙과 검증은 독립된 장면이다. 각 로컬 장면을 수평으로 나누고 경계 한 열을 제외했다. 같은 로컬 풀을 Non-IID에서는 장면별로, IID 근사에서는 양 장면의 띠를 섞어 크기·클래스 분포 차이가 작은 조합으로 배정했다. 중앙과 로컬은 클래스별 해시 표집으로, 검증은 균일 해시 표집으로 패치 수를 제한했다. 독립 검증 장면은 하나다.

GTv3 PLY의 class 필드와 WMSC 캐시의 원시 ID 변환을 공식 KPConv의 공통 6-class 매핑과 대조했다. instance 필드는 사용하지 않았다. 직접 읽은 원시 클래스 히스토그램, 양 도메인의 유효 복셀 빈도, 기존 WMSC 캐시 외부 인덱스는 별도 파일로 보관했다. [공식 변환 코드](https://github.com/meidachen/STPLS3D/blob/main/KPConv-PyTorch/datasets/STPLS3D.py#L573-L613) · [데이터 manifest](dataset_manifest.json)

## 학습 및 선택

RTX A6000 한 장, CUDA 12.6, PyTorch 2.8.0+cu126, seed 42, batch 8, AMP. 별도 1 epoch smoke 성공 후 무작위 초기화한 기준 모델을 AdamW 1e-3와 cosine annealing으로 20 epochs 학습했다. 모든 실험은 같은 최적 합성 validation 체크포인트에서 유래한다. 채택 epoch는 10이다. 기존 WMSC 학습 가중치는 로드하지 않았다.

각 비율에서 AdamW LR 1e-4/1e-3 × 5/10/20 epochs를 비교했다. 한 LR 안에서 optimizer를 유지했으며 선택은 합성 validation mIoU 최대, 동률이면 짧은 학습과 낮은 LR 순이다. 40% 직후 validation 하락이 0.05 이상이면 단계적 20→40% 후보도 같은 총 epoch로 비교했다. 이 후보는 두 번째 축소 후 optimizer를 초기화한다. 원본에도 같은 추가 epoch·LR을 적용하여 보조 대조군을 만들었다.

FedAvg는 모든 비교에서 10 rounds, 1 local epoch, LR 1e-4로 고정해 두 클라이언트를 순차 학습했다. 샘플 수로 파라미터와 BN 평균·분산을 가중평균하고 BN batch counter는 최댓값을 쓴다. WMSC 평가 시작 전에 최종 모델 경로·해시·학습량을 고정했다. [선택 기록](pruning_results.csv) · [최종 모델 목록](frozen_models.json)

통신량은 전체 모델을 두 클라이언트에 배포하고 수신한 텐서 크기의 합이다. 실제 무선 전송을 측정하지 않았다. FL과 시작점 차이에는 추가 로컬 학습 효과도 포함된다. 훈련 peak는 해당 단계의 CUDA 학습 로그, 추론 peak는 최종 체크포인트 단일 패치 프로파일이다. 상세 지표에는 도메인별 Macro F1·Accuracy·클래스별 IoU도 있다.
